# Atividades bônus extras: Modelagem de Domínio

O repositório reúne as anotações, soluções, códigos Java e representações produzidas nas atividades da disciplina. Cada atividade possui uma pasta própria para facilitar a consulta e a apresentação.

## Organização

- `aula01` — introdução à modelagem, modelos mentais e evolução das técnicas;
- `aula02` — introdução ao projeto orientado pelo domínio;
- `aula04` — contextos delimitados e subdomínios;
- `aula05` — design estratégico e mapeamento de contextos;
- `aula06` — padrões táticos de design;
- `aula07` — arquitetura e modelos de domínio.

## Executando exemplos Java

Os exemplos não usam Maven ou Gradle. Em uma pasta de atividade, execute:

```powershell
javac -d $env:TEMP\md-build .\src\*.java
java -cp $env:TEMP\md-build Main
```
