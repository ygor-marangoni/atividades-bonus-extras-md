# ACL, OHS e PL (1)

## Identificação

- Aula: 5.1
- Tema: contratos de integração
- Tipo: explicação

## Solução

**Open Host Service (OHS)** é um serviço oferecido por um contexto para vários consumidores por meio de uma interface estável. **Published Language (PL)** é a linguagem/documentação de dados compartilhada que permite interpretar esse contrato. Uma **ACL** fica no consumidor e converte o contrato publicado para o seu próprio modelo.

Portanto, OHS e PL facilitam a exposição consistente; ACL protege quem consome. Eles podem coexistir: um catálogo oferece endpoints e um esquema documentado, enquanto Reservas traduz a resposta para seus objetos internos.
