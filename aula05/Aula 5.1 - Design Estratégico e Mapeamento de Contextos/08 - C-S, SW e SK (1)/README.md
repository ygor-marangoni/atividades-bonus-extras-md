# C/S, SW e SK (1)

## Identificação

- Aula: 5.1
- Tema: padrões C/S, SW e SK
- Tipo: comparação

## Solução

**Customer/Supplier (C/S)** organiza a relação quando uma equipe fornecedora prioriza uma integração considerando as necessidades do cliente interno. **Separate Ways (SW)** aceita que contextos similares sigam independentes, sem integração. **Shared Kernel (SK)** compartilha uma pequena parte do modelo.

Use C/S quando a colaboração for necessária e as equipes puderem negociar prioridades. Use SW quando integrar custa mais que duplicar uma capacidade simples. Use SK somente quando há conceito realmente comum, estável e governado por ambas as equipes.
