# Domínio Central

## Identificação

- Aula: 2.1
- Tema: Core Domain
- Tipo: classificação

## Solução

Para o projeto Merco, que aproxima pequenos produtores e compradores locais, o domínio central é a composição de pedidos com disponibilidade real do produtor e janelas de retirada/entrega. Esse ponto diferencia a plataforma de um catálogo comum, pois precisa conciliar produção limitada, sazonalidade e compromisso de entrega.

| Área | Classificação | Motivo |
|---|---|---|
| Oferta e reserva de produtos | Domínio central | concentra a proposta de valor e regras próprias |
| Cobrança | Subdomínio genérico | pode usar serviço especializado, com regras locais mínimas |
| Cadastro de usuários | Subdomínio de suporte | necessário, porém não diferencia o negócio |

## Reflexão pessoal

Classificar não diminui as áreas de suporte; apenas ajuda a direcionar mais atenção onde existe maior risco e valor estratégico.
