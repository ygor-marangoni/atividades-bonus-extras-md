# Limitações

## Identificação

- Aula: 2.1
- Tema: limites do DDD
- Tipo: reflexão técnica

## Solução

DDD exige tempo de conversa com especialistas e disciplina para manter o vocabulário. Por isso, pode ser desproporcional para uma página institucional, um formulário simples ou uma automação de uso interno sem regras relevantes. Também não resolve, sozinho, problemas de desempenho, infraestrutura, acessibilidade ou segurança.

Em um sistema pequeno, introduzir agregados, eventos e várias camadas sem necessidade pode aumentar a dificuldade de manutenção. A decisão adequada é observar a complexidade do domínio: regras conflitantes, exceções frequentes e vocabulário especializado são sinais favoráveis; operações previsíveis e estáveis pedem uma solução mais direta.

## Resultado

DDD é uma forma de lidar com complexidade de negócio, não um substituto automático para todo tipo de arquitetura ou prática de engenharia.
